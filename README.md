# 資産メモ PWA v4.91

普段の起動はパスワード不要の、端末内保存型の資産メモです。入力内容を外部サーバーへ同期・送信する機能はありません。

## 使い方

1. [アプリを開く](https://ssii401452-max.github.io/assetmemo-pwa/)。既存のホーム画面アプリも同じURLのまま利用します。
2. バックアップは「設定」→「ファイルとして保存」または「JSONを表示」で作成します。このときだけ12文字以上のバックアップ用パスワードを設定します。
3. 作成後に「共有・ファイルに保存」「ダウンロード」「JSONをコピー」のいずれかで別の場所へ保存してください。パスワードを忘れるとバックアップを復元できません。
4. 復元は「バックアップ読込」から。復号・内容検証・置換確認が終わるまで現在の記録は変更しません。

## 旧版からの更新

- 旧版のタブを全て閉じ、インターネットに接続して同じURLを開き直してください。旧版データは一度だけ自動移行します。
- 移行が成功したら、新しい形式でバックアップを作り直してください。既に保存した旧バックアップの弱い暗号化は更新では変わりません。
- 読み込みに失敗しても元データを自動初期化しません。復旧画面の「元データを保存」は調査用の暗号文で、通常の持ち運び用バックアップとは異なります。
- ブラウザのサイトデータを消すと端末内の鍵も失われます。バックアップを先に保存してください。

## 検証

Node.js 20以降を使用します。実行時依存はなく、npmはテスト時だけ必要です。

```sh
npm ci
npm test
```

実ブラウザの回帰テストにはPlaywrightとChromiumが必要です。

```sh
npm install --no-save playwright
npx playwright install chromium
npm run test:browser
```

既存のChromiumを使う場合は `CHROMIUM_PATH` で実行ファイルを指定できます。

JavaScriptを編集したら `npm run update:csp` でCSP/SRIハッシュを再生成してください。ファイル一式を同じコミットで公開します。

修正内容、検証範囲、制約は [SECURITY.md](SECURITY.md) を参照してください。
